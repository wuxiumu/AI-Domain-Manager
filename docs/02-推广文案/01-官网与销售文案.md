## 2. 三种长度的产品介绍

### 简短介绍

资产工作台：统一查看多账号域名、IP、用途备注和站点关联，支持健康检查与私有化部署。

### 产品卡片介绍

域名分散在多个云账号，IP 的用途记在表格里，网站入口还要到处翻？资产工作台把这些资料放在一个界面：搜索域名或 IP，查看用途与备注、关联站点和最近检查结果，再进入对应网站或管理 DNS。支持阿里云、腾讯云和 GoDaddy 多账号接入，可部署在自己的服务器上。

### 对外详细介绍

资产工作台面向维护多个网站的个人和小团队，帮助你整理域名、IP、网站入口与关联资料。

你可以接入阿里云、腾讯云和 GoDaddy 账号查看域名，也可以手工登记公网 IP，为资产补充用途、备注和网站链接。查一个域名，可以查看关联 IP；查一个 IP，可以查看已经登记或观察到的关联站点。DNS 观察与人工确认绑定分别展示，方便核对资料。

日常打开就是搜索与列表，更多筛选从按钮下方展开；需要时查看统计或关联图。支持单次及批量检查，结果与时间保存在部署实例中，便于下次继续查阅。

资料可导出、交接可核对。支持 JSON 迁移与预览恢复、CSV 资产表、恢复前自动备份，以及基础操作记录和交付摘要。资产导出不包含云凭据和登录配置，客户可以保存自己的台账。

提供客户自有服务器部署与使用交接服务；自动提醒、多人权限等增强需求可单独评估。

### 场景区

**接手一批网站，先把资料查清**

域名在哪个账号、IP 用来做什么、网站入口在哪里，把资料放进同一份可搜索台账，减少交接时反复找人确认。

从 IP 查看已经登记和观察到的域名及子域名，结合人工确认绑定，整理本次迁移需要核对的站点。

查看检查时间和证据，区分未检查、过时与当前结果；需要时发起单次或批量检查。

## 8. 客户咨询回复模板

### 为什么我已经有云控制台，还需要它？

云控制台负责对应平台的资源操作。这个工作台把多个账号的域名，以及手工维护的 IP 用途、网站入口和人工绑定放在一个界面，方便跨账号查资料和做交接。是否适合你，可以用你平时最常做的一次查找来演示判断。

### 和现成的网站监控有什么区别？

这里主要帮助你整理域名、IP 和站点关联，也能做手动检查。如果你最需要持续监控与即时通知，可以先继续使用现有监控工具，再评估是否需要补充这份资产台账。

### 数据和云密钥放在哪里？

客户自有实例部署时，资产资料与云凭据保存在该实例中；应用调用云商接口时会使用这些凭据，界面查询不会回显完整秘密。部署协助时由你自己填写凭据。若你额外连接外部 AI 或其他服务，传给它的数据范围需要按授权单独确认。

### IP 显示正常，是否就说明所有网站都正常？

当前 IP 检查访问 `http://IP/`，2xx / 3xx 视为正常，且不会继续跟随跳转。这表示该次 IP HTTP 入口检查符合规则，关联网站仍需结合域名、HTTPS 和具体业务检查判断。

### 会自动提醒到期或异常吗？

当前提供到期筛选和手动检查结果查看，后台定时检查与外部通知尚未作为标准功能交付。如果这是你的必需项，我们先明确渠道、频率和验收要求，再评估增强方案。

### 支持几个人使用？能给我的客户分别登录吗？

当前是单管理员版本，API 密钥可以按操作范围授权，但不等于多人角色或客户之间的数据隔离。如果你要给不同客户分别登录，需要先做独立实例，或另行评估隔离与权限功能。

### 能用 AI 管理吗？

当前有 OpenAPI 和分权限 API 密钥，可以对接支持相应接口的脚本或 AI 工具。具体工具的导入方式和网络可达性需要验证；产品目前没有内置聊天助手。建议先从只读查询开始，DNS 修改等写入能力按需要单独授权。

### 价格包含服务器和长期代维吗？

基础报价对应确认范围的部署、资料整理和交接。服务器、域名、长期维护与额外定制另行确认。我们会先列清本次交付内容和人工服务上限，再开始实施。

### 能管理多少资产？

需要结合数据量、部署环境和检查频率评估。目前不承诺无限规模；如果你的资产量较大，可以先用脱敏或合成数据验证，再确定交付范围。
