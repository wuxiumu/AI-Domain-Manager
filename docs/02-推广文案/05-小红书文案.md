# 网站多了以后，我把域名和 IP 资料放进同一个工作台

状态：小红书草稿，配图须用合成演示数据重新制作。

域名放在不同云账号，IP 的用途记在表格里，网站入口还要翻收藏夹。

现在整理到一个资产工作台：

- 搜域名或 IP，查用途与备注。
- 看已知站点关联，辅助交接和迁移核对。
- 点网站名称，打开对应入口。
- 手动检查，保留结果与时间。

目前支持阿里云、腾讯云、GoDaddy 多账号，也可以手工登记公网 IP。打开直接看列表，更多筛选和图表按需展开。

当前是单管理员、手动检查版本，可评估部署到自己的服务器上。适合正在整理多个网站资料的个人和小团队先看演示。
