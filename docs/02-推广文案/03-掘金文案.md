# 多账号域名与 IP，整理成一个可搜索的资产工作台

状态：掘金投稿草稿。演示只用合成数据；发布时填入已审核的项目与演示入口。

维护多个网站时，经常需要先回答几个问题：域名在哪个账号？这个 IP 用于哪个站点？准备迁移时，需要核对哪些关联？

资产工作台把域名、IP、用途备注和网站入口集中在同一个界面。打开先看到搜索与列表，筛选从搜索框前的按钮展开，统计和关系图按需查看。

## 当前做了什么

- 接入阿里云、腾讯云和 GoDaddy 多账号域名。
- 维护 IP 用途、备注和多个网站链接。
- 通过列表和关系图查看 DNS 观察及人工确认绑定。
- 手动执行域名和 IP 检查，保存时间与结果。
- 提供 OpenAPI 与分权限 API 密钥，方便脚本和外部工具接入。

## 使用时需要理解的数据边界

刷新快照、同步云端和执行检查是不同动作。DNS 观察只提供解析线索，单次 IP HTTP 检查只反映该入口当时的响应，页面会保留结果时间。

当前是单管理员版本，批量检查需要保持页面打开。后台定时任务、异常通知和多人权限还在规划。

如果你在维护多个站点，可以先用一次日常查找或交接任务评估是否合适。我们也提供客户自有环境部署的范围评估。
