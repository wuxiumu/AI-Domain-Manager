# 用 OpenAPI 连接域名与 IP 资产工作台

状态：技术推广稿，未执行发布。文中只使用示例地址，功能以当前发布版本为准。

## 从统一台账开始

维护多个网站时，域名、IP、网站入口与用途备注往往分散在多个账号和表格中。资产工作台把这些资料放进统一的搜索与列表，也提供接口供脚本和支持相应接口的 AI 工具查询。

当前支持阿里云、腾讯云和 GoDaddy 多账号域名管理、DNS 维护、域名与 IP 关联及手动检查。

## 对接入口

| 入口 | 用途 |
| --- | --- |
| `/api/openapi.json` | OpenAPI 接口契约 |
| `/.well-known/asset-workspace.json` | 能力与认证发现 |
| `/llms.txt` | 外部工具调用说明 |

在产品设置中创建有有效期、可撤销的 API 密钥。建议先只授权资产与 DNS 查询，需要修改时再明确增加对应写权限。

下面仅演示同机读取，Token 由调用方安全提供，不把真实值写进文章或命令历史：

```sh
export WORKSPACE_URL='http://127.0.0.1:8080'
python3 scripts/workspace-api.py GET /api/health
python3 scripts/workspace-api.py GET /api/domains
```

调用方还需要按客户端说明设置 `WORKSPACE_API_TOKEN`。远程工具须能访问部署地址，并通过 HTTPS 连接；本机回环地址只适合同机调用。

## 可以从哪些场景试用

- 查询域名、IP、用途备注和已知关联。
- 汇总最近检查结果，同时保留时间与证据。
- 读取缓存 DNS 记录，核对云账号与记录标识。
- 在单独授权并确认范围后，调用写接口维护资料或 DNS。

产品提供的是接口基础，具体 AI 工具的导入和调用方式需要验证；目前没有内置聊天助手。AI 只能基于已提供的资料分析，不能把已知关联包装成完整影响面，也不能把单次 IP HTTP 正常解释成全部网站业务正常。

## 部署和功能范围

可部署在自己的环境中，凭据保存在该实例的私有配置里。当前为单管理员、手动检查版本；后台任务、外部通知和多人权限另行规划。
