# 客户需求确认清单 · 域名管家定制部署

> 用途：接「定制工作台部署」订单时，发给客户填写，标准化确认范围、环境与安全要求。填写完即成为后续报价与合同的基础。
> 使用建议：先由客户填写前八部分，服务方根据结果评估报价；「服务范围与交付确认」在成交时双方共同勾选。

> 2026-10-27 能力校准：1.1.0 已有资产 JSON 迁移与预览恢复、CSV 导出、基础操作记录和交付摘要；当前仍为单管理员、手动检查版本。后台任务、外部通知、多人权限、CSV 导入和完整操作审计均需单独评估，勾选需求不代表已包含。套餐与报价假设见 [商业化方案](../03-计划方案/02-商业化方案.md)。

## 九、服务范围与交付确认（成交时双方勾选）

**本次包含**
- [ ] 远程部署（环境检查 → 部署 → 首次配置）
- [ ] 云账号接入 + 连接测试
- [ ] 现有资产迁移（CSV 导入 + 对账）
- [ ] 交付培训（一次，远程）
- [ ] 验收清单核验

**本次不包含（需另行报价）**
- [ ] 后续功能定制开发
- [ ] 长期维护 / 更新 / 技术支持（属订阅项）
- [ ] 多人权限、外部通知等增强功能
- [ ] 超出约定范围的售后

**交付确认**
- 基础验收标准：能从域名查看已知 IP 关联、从 IP 查看已登记或观察到的关联站点、更新用途备注及网站链接、执行一次手动检查并核对结果与时间；按约定完成备份恢复验证。
- 通知增强项验收（仅在单独约定时）：后台执行、异常通知、恢复通知、通知失败记录与重试均按约定验证。
- 维护期：自验收之日起 ______ 天。
