## 🔑 AI 接入怎么做到「放心」

这点最戳我 ⬇️

🔒 密钥分权限：AI 默认**只能读不能改**，要改得你授权
🔒 密钥本地保存、不来回显
🔒 有有效期、随时可撤销
🔒 每次操作可审计，不是黑盒点按钮

AI 能操作你资产，但权限你说了算 ✅

---

## 🚀 上手就 3 步

1️⃣ 产品设置里创建一个 **分权限 API 密钥**
2️⃣ 把地址和密钥给 AI（支持 OpenAPI 3.1 + llms.txt，AI 自己就会用）
3️⃣ 让它按「先查后改」操作：先读列表 → 再改记录 → 只改该改的
