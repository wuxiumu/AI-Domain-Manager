## 资料边界

- 产品介绍只描述当前能力，推广文案按当前发布版本核对，计划方案明确标注未实现内容。
- 仓库不保存真实域名、服务器 IP、客户账号、实例资产统计、运行快照或生产环境截图。
- 示例使用 `example.com` 及其子域名、文档专用 IP 或本机回环地址，不映射真实资产。
- 本地台账、导出和截图放在仓库外，或已忽略的 `.local/` 目录；不要把真实材料移到另一个可提交的“归档”目录。
- 本目录可随代码仓库公开；它不提供访问控制。内部计划若也需保密，应另存于不发布的位置。

发布前执行 `python3 scripts/check-public-docs.py`。具体规则与历史泄露处理边界见 [文档发布与脱敏规范](04-交付与维护/03-文档发布与脱敏规范.md)。
