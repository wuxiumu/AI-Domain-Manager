# 资产工作台：产品概览

资产工作台用于统一查看多账号域名、IP、用途备注和网站入口，帮助个人及小团队查找资产资料、核对关联并执行检查。可部署在客户自己的环境中。

当前版本：1.2.0。已有资料迁移、可恢复交付、登录验证码和服务端限流；DNS 变更新增差异预览、旧版本核对、云端回读及前后值记录。

## 当前能力

| 模块 | 功能 |
| --- | --- |
| 健康看板 | 搜索和筛选资产，查看检查状态、时间与证据，手动执行单次或批量检查 |
| 资产关系 | 通过列表和关系图查看域名、子域名及 IP；区分 DNS 观察与人工确认绑定 |
| 域名管理 | 接入阿里云、腾讯云、GoDaddy 多账号，显式同步、维护本地资料与云端 DNS |
| IP 资产 | 手工登记公网 IPv4 / IPv6，维护名称、用途备注和多个网站名称及 URL |
| 云账号 | 新增、编辑、删除、启用 / 停用和备注，测试账号连接 |
| 产品设置 | 首次管理员配置、登录信息、接口代理和分权限 API 密钥 |
| 数据与交付 | 资产备份、JSON 导出与预览恢复、CSV 导出、部署自检、交付摘要和基础操作记录 |

四个资产页面默认展示操作栏、搜索与列表。筛选按钮位于搜索框之前，更多选项从按钮下方展开；统计和关联图按需打开。桌面列表使用剩余视口高度，表头与主要操作列固定。

## 结果如何理解

- 同步、刷新快照和执行检查是不同操作，读取缓存不代表进行了新探测。
- 同步全部失败或没有启用账号时保留上次成功同步时间；部分失败明确提示，失败账号继续使用旧资料。
- 域名检查包含 DNS / HTTPS，HTTPS 校验证书。
- IP 检查访问 `http://IP/`，2xx / 3xx 视为正常，不继续跟随跳转；这不等于关联网站的业务一定正常。
- 未检查和结果过时分别展示，不应算作当前正常。
- DNS 解析关系可能指向 CDN 或代理入口，源站归属需结合人工确认。

## 使用边界

JSON 迁移文件和服务器备份保留域名、手工 IP、备注、网站链接与人工绑定，排除云凭据、管理员配置、API 密钥、云原始响应和检查缓存。恢复是全量替换，先预览并验证密码，自动留底；未配置的云账号来源转为手工资产并调整绑定标识。CSV 用于交接，不支持直接导入。详情见 [备份恢复说明](../04-交付与维护/04-备份恢复与版本交付.md)。

基础操作记录覆盖通过登录与权限校验后的写请求，保留操作者、路由、时间和执行结果；没有请求正文或 DNS 修改前后差异，也不属于不可篡改审计系统。

当前是单管理员版本。批量检查由浏览器分批发起，需要保持页面打开。后台调度、外部通知、多人角色、多客户隔离和自动恢复属于后续方案，不能当作已交付能力。

OpenAPI 和分权限 API 密钥为脚本及外部工具提供接入基础；产品没有内置聊天助手。云凭据保存在部署实例的私有配置中，查询接口不回显完整秘密。
